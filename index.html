Hand off issues to coding agents. Only when they're ready.

A vague ticket gives you a confident, wrong pull request. Groundwork checks each Jira issue against seven explainable checks, tells the reporter what to fix, and writes the brief your agent needs.

    Where it lives in Atlassian
    Three Forge surfaces, one engine. Data never leaves Jira; calls run with the user's own permissions.
    

    

    Issue panel
    jira:issuePanel in UI Kit. A verdict, every failing check with its fix, a brief preview and one-click Hand off to agent.
    

    Rovo agent
    rovo:agent. Ask "Is this issue ready for a coding agent?" in Rovo chat and get the gaps in plain words.
    

    Reusable actions
    check-readiness, get-agent-brief, post-agent-handoff. Any Rovo agent can call them as tools.
    

    

    Handoff refuses when acceptance criteria are missing or an open issue blocks the work. Groundwork never invents criteria, paths or decisions.
